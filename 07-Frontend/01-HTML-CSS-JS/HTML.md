# 📌 HTML 学习笔记

## 1. 🎯 前置说明
- **学习动机**：全栈包括前端，前端最基础的便是HTML。
- **核心定义**：
	- HTML（HyperText Markup Language，超文本标记语言）是构建网页内容的基石。
	- 它是通过“标签”来为文本、图像、链接等内容赋予结构与语义。
	- 标签通常成对出现，分为起始标签`<h1>`和结束标签`</h1>`。但也有一部分是单独出现`<br>`。
- **前置知识**：无。这是web开发最基础的入门课，只需会使用文本编辑器(类似vs code)和浏览器即可。

## 2. 🧩 核心知识点
### 2.1 底层逻辑与核心原理 (What & Why)
#### 1. 为什么是“超文本”（HyperText）？
普通文本（如‘.txt'文件）只能原样的显示字符，而**超文本**在文本之外，还具备两大核心能力：
- **结构化**：通过标签定义内容的层级关系（如标题、段落、列表）；
- **语义化**：告诉浏览器每一部分内容的“身份”（如`<h1>`是主标题`<a>`是链接）。
  > 💡 通俗理解：**文本告诉你“写的是什么字”，超文本告诉你“这些字是什么角色”。**
#### 2. 为什么浏览器能看懂 HTML？
浏览器内置了**HTML解析引擎**。当你把`.html`文件交给浏览器时，他会经历以下流程：
1.**读取**：逐行读取代码字符串；
2.**解析**：将标签解析为**DOM树**（一种内存中的层级结构模型）；
3.**渲染**：根据树形结构计算每个元素的位置和样式；
4.**绘制**：最终绘制成你看到的图形化页面。
#### 3.为什么用“标签”这种形式？
标签的成对结构(`<父><子></子></父>`)天然支持**嵌套**，能清晰表达内容的**树形层级关系**。
#### 4.HTML是编程语言吗？
**HTML 与编程语言的根本区别 **

| 对比维度 | HTML | 编程语言 |
| :--- | :--- | :--- |
| 核心能力 | 描述内容结构和外观 | 处理数据和逻辑（计算，判断，循环） |
| 有无逻辑 | ❌无变量、条件、循环 | ✅具备完整的逻辑控制 |
| 运行结果 | 渲染出静态页面结构 | 输出计算结构或执行动作 |
| 学术称谓 | 标记语言 | 编程语言 |
### 2.2 常用的文本标签(How)
HTML提供了丰富的标签来处理文本内容。根据其显示特点，标签可划分为两大类，而在文本标签中，我们需要区分它的**语义**和**显示效果**。
#### 1.块级元素和行内元素的区别
|类型|特点|常见标签|类比|
| :--- |:--- |:--- |:--- |
|**块级标签**|独占一行，默认宽度为100%，前后有换行| `<h1>`~`<h6>`,`<p>`,`<div>`|像一个大盒子上下排列|
|**行内标签**|不换行，宽高由内容撑开|`<a>`,`<strong>`,`<span>`|像排队一样，从左排到右|

#### 2. 常用文本标签详解
| 标签              | 语义/作用                 | 类型  | 示例效果             |
| :-------------- | :-------------------- | :-- | :--------------- |
| `<h1>` ~ `<h6>` | 标题（1级最大，6级最小）         | 块级  | **<h1>大标题</h1>** |
| `<p>`           | 段落                    | 块级  | 自动换行，段间距         |
| `<br>`          | 强制换行（自闭合标签）           | 不参与 | 第一行<br>第二行       |
| `<hr>`          | 水平分割线（自闭合标签）          | 不参与 | 一条横线（视觉分隔）       |
| `<strong>`      | 表示**重要内容**（语义强）       | 行内  | **加粗**（屏幕阅读器会重读） |
| `<b>`           | 仅视觉加粗（无语义）            | 行内  | **加粗**（仅用于样式）    |
| `<em>`          | 表示**强调内容**（语义重）       | 行内  | *斜体*（语气加重）       |
| `<i>`           | 仅视觉斜体（无语义）            | 行内  | *斜体*（常用于图标或专业术语） |
| `<u>`           | 表示下划线（无语义）            | 行内  | <u>下划线</u>       |
| `<del>`         | 表示删除的内容               | 行内  | ~~删除线~~          |
| `<span>`        | 通用行内容器（**无语义**，纯样式钩子） | 行内  | 常用于包裹文字单独改颜色     |
| `<div>`         | 通用块级容器（**无语义**，布局大盒子） | 块级  | 用于划分页面区域         |

#### 3. 语义化的重要性（Why 的延伸）
- **有语义（`<strong>`、`<em>`、`<h1>`）**：告诉浏览器“这个内容很重要”、“这是一级标题”。有利于 **SEO（搜索引擎优化）** 和 **无障碍访问（盲人读屏软件）**。
- **无语义（`<b>`、`<i>`、`<span>`、`<div>`）**：纯粹为了改变样式，对搜索引擎不友好。**未来学习 CSS 时，我们会频繁用它们来“化妆”。**
> 💡 **记忆口诀**：**标题段落用块级，加粗斜体用行内；`div` 和 `span` 是万能盒子，一个独占一行，一个随波逐流。**

#### 2.3 链接与图片

##### 1.超链接`<a>`

**`<a>`具有的属性**

|    属性    |                  作用                   |                          实例                          |
| :------: | :-----------------------------------: | :--------------------------------------------------: |
|   href   |       **超链接的地址目标**，指定连接要跳转的URL        |           `<a href ="https://baidu.com">`            |
|  target  |         **链接的打开方式**,定义链接在何处打开         |            `self`(当前窗口默认)、blank(新窗口或标签页)             |
| download |     **触发**下载，告诉浏览器下载链接资源而不是跳转到网页      |       `<a href="/file.pdf" download="新文件名.pdf`       |
|   rel    |       **文档关系**，定义当前文档与链接目标之间的关系       | `nofollow`（告诉搜索引擎不传递权重）`noopener noreferrer`（安全属性组合） |
| hreflang |         **目标语言**，提示链接目标文档的语言          |            `<a href="..." hreflang="en">`            |
|   type   |      **目标MIME类型**，提示链接目标的MIME类型       |       `<a href="..." type="application/pdf">`        |
|   ping   | **发送追踪通知**，当链接被点击时，浏览器会向指定URL发送POST请求 |  `<a href="..." ping="https://track.example.com">`   |
###### 1)链接的核心是“跳转”，那么它最关键的“生命线”是什么？
- 链接之中最重要的属性就是`href`，由上述的表格可以看到，不论是是什么标签都是基于`href`进行操作的，如果失去它那么链接便不是链接。
  >链接最关键的生命线便是`href`

###### 2)点击链接后，页面是怎么打开的？
- 回顾我们在平时打开网页，有的网页会在当前窗口打开，覆盖掉原本的窗口，有的窗口会在新窗口或标签页中打开。影响这个效果的便是`target`。
- `target`**是链接的打开方式**，其中`self`(当前窗口默认)、blank(新窗口或标签页)

###### 3) 链接只能跳转到别的网站吗？能不能跳到自己页面的某个位置？
- 平时上网的时候，便可以看到一些较长的网页，会提供目录，点击对应章节便可以跳到对应位置。这便是运用了**锚点链接**的写法，在`href`属性里，不填写任何网站，而是填写对应标签的id，这样便可以跳到相应位置。
- 除了填写网站和id，还可以写#，填写这个的效果，类似刷新了一下网页

##### 2.图片`<img>`

**`<img>`的常用属性**

|      属性名      |                                     作用                                     |
| :-----------: | :------------------------------------------------------------------------: |
|     `src`     |                        **（必需）** 图片的 URL 地址，决定显示哪张图。                        |
|     `alt`     |                     **（必需）** 替代文本，图片加载失败时显示，并用于屏幕阅读器。                      |
|    `width`    |                        图片显示宽度（像素），提前预留空间，避免页面布局抖动。                         |
|   `height`    |                     图片显示高度（像素），与 `width` 配合保持比例或预留空间。                      |
|   `loading`   |               懒加载控制：`lazy`（滚动到附近才加载）或 `eager`（立即加载，默认）。优化性能。               |
|   `srcset`    |                提供多张不同分辨率的图片（如 `1x`、`2x`），配合 `sizes` 实现响应式。                 |
|    `sizes`    | 声明图片在布局中的预期显示宽度（如 `(max-width: 600px) 100vw, 50vw`），帮助浏览器选择最佳 `srcset` 资源。 |
| `crossorigin` |    跨域请求设置：`anonymous`（不带凭证）或 `use-credentials`（带凭证），用于 Canvas 处理第三方图片等。    |
###### 1）`<img>` 标签和 `<a>` 标签最大的不同是什么？（从“写法”和“内容”两个角度）

- `<img>`和`<a>` 两标签都需要指定内容的地址。`<img>`指定的图片对应的地址，决定显示哪张图片；`<a>`
